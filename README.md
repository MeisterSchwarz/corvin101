## ✨ Features

### 🎮 Discord Rich Presence

Corvin automatically reflects your current game state on Discord.

Currently displayed:

- Current world and area
- Roaming or combat status
- Character selection
- World-specific artwork

### ⚔️ Battle Overlay

See the current combat round and known enemy affinities during the planning phase.

<p align="center">
  <img src="public/preview_battle.png" width="100%" alt="Battle overlay showing enemy affinities and the current combat round">
</p>

### 📖 Bestiary

Browse and search enemies by world to view their schools, damage modifiers and locations. Combat enemies appear first with crossed swords, followed by enemies in your current area.

- Switch between stats, drops, and cheats with strategies
- View known item drops and gold ranges
- Read cheat mechanics, round cycles and strategy tips; click enemy references to open their entries
- Toggle Standard and Challenge variants for individual enemies or entire boss groups
- Browse multi-part bosses such as Balaur and the Tri-bunal Judges in one entry, with separate stats selected through school symbols

Open or close with **Tab**, select a world from the title, and turn pages with the **mouse wheel over the list** or the **page buttons**.

## 🛡️ Windows Security Notice

Corvin is currently **not code signed**.

Because of this, Windows SmartScreen or Microsoft Defender may display a warning when downloading or launching the application.

This does not necessarily indicate that Corvin is malicious — unsigned applications from unknown publishers can trigger these warnings.

The complete source code is available in this repository for transparency.

---

## 🔒 Privacy

Corvin processes Wizard101 log data locally.

Network communication is limited to:

- Discord Rich Presence
- Downloading game data from RavenDex

No user account is required.
